# Support

AirBridge is an open-source project. Support is provided on a best-effort basis.

## Where to ask for help

Use GitHub issues for:

- Bug reports.
- Feature requests.
- Documentation improvements.
- Field compatibility reports.
- Restore failure reports with sanitized details.

## Before opening a support issue

Please check:

- `docs/troubleshooting.md`
- `docs/faq.md`
- `docs/field-compatibility.md`
- `docs/restore-limitations.md`
- Existing issues

## What to include

For bug reports, include:

- AirBridge version.
- Operating system and version.
- Airtable workflow affected.
- Steps to reproduce.
- Expected result.
- Actual result.
- Error code, if available.
- Sanitized logs, if safe to share.

## What not to include

Do not include:

- Airtable Personal Access Tokens.
- Real customer data.
- Private attachment URLs.
- Full backup packages containing sensitive data.
- Screenshots containing confidential data.

## Security issues

For security vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
