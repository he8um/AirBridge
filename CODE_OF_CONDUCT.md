# Code of Conduct

AirBridge is an open-source project intended to be practical, respectful, and safe for contributors and users.

## Expected behavior

Participants are expected to:

- Be respectful and constructive.
- Assume good intent while focusing on facts and reproducible behavior.
- Keep discussions relevant to the project.
- Avoid harassment, personal attacks, or hostile communication.
- Respect privacy and never request unnecessary sensitive data from users.
- Use sanitized examples when discussing backup packages, logs, or Airtable base content.

## Unacceptable behavior

Unacceptable behavior includes:

- Harassment or discrimination.
- Personal attacks.
- Publishing private information.
- Pressuring users to share sensitive data.
- Deliberately disruptive comments.
- Threats or abusive language.

## Reporting

Report conduct concerns through the contact method listed in `SUPPORT.md` or `SECURITY.md`, depending on the issue.

## Enforcement

Maintainers may moderate, edit, hide, or close issues and pull requests that violate this code of conduct. Repeated or severe violations may result in being blocked from participating in the project.
