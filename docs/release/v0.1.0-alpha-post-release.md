## Known Limitations Accepted for Alpha

See [known-limitations.md](known-limitations.md) for the full list. Items accepted as deferred for this release:

1. Restore write execution disabled by policy — planning complete, live writes require product and security approval.
2. Attachment binary handling not implemented — metadata and URLs captured only; file bytes not downloaded or restored.
3. Credential auto-fill not implemented — saved keychain token not yet wired to operations.
4. Job history in-memory only — not persisted between restarts.
5. Linux and Windows smoke tests deferred — no build environment available at publish.
6. Full macOS UI walkthrough deferred — backup flow, package inspection, restore planning end-to-end.
7. macOS `.dmg` is not notarized — Gatekeeper may warn on first launch.
8. Windows installer not code-signed — SmartScreen may warn on first launch.
